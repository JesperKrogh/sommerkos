# Agent Instructions

## Always Git Commit

After completing any task, create a git commit with a descriptive message. Use `git add .` to stage all changes, then `git commit -m "description"`.

## Project

- Vite-based project
- Run dev server: `npm run dev`
- Lint: `npm run lint` (if available)

## Testing

- Use `playwright-cli` for browser testing
- Run tests: `npx playwright-cli test`
- Open UI: `npx playwright-cli open`
